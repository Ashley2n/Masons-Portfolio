- **Playwright `click()` re-scrolls on the phone project:** measured 2026-11-14, a button parked at the edge of the viewport moved about 410px just before the click landed. If a test compares scrollY before and after a click, call `locator.click({ trial: true })` first and measure after it (`e2e/media.spec.ts`, "Load more" test).

- **Hover tests only on desktop:** Tailwind wraps `hover:` in `@media (hover: hover)`, so the `mobile` (Pixel 7) project has no hover lift; skip it with `test.skip(testInfo.project.name === "mobile", ...)`.
