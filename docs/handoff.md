## Gotchas
- **The Claude in Chrome tool's `resize_window` does not change the viewport** (`innerWidth` stayed 1920). For 390 px screenshots use the Playwright MCP (`browser_resize`, `browser_navigate`, `browser_click`, `browser_take_screenshot` with a `.playwright-mcp/` filename). Playwright e2e specs set their own viewport with `page.setViewportSize`.
- **`impeccable live-generate`:** after the helper injects its script into `app/layout.tsx` you must reload the tab, then rerun the command, or it reports `no_browser_connected`. `live-server stop` restores `app/layout.tsx`. A header variant needs `position: sticky` and the preview wrapper (`display: contents`) can break it; the hero already pulls under the header with `-mt-(--header-height)`, so keep any sticky header in the flow.
- **Testing a swipe in Playwright:** `Input.synthesizeScrollGesture` (CDP) did nothing under Pixel 7 emulation; real touch events work: `cdp = await page.context().newCDPSession(page)`, then `Input.dispatchTouchEvent` `touchStart`, ten `touchMove`s, `touchEnd`. Desktop Chrome has no touch unless the spec calls `test.use({ hasTouch: true })` (done in `e2e/model-shots.spec.ts`). Wait about 800 ms after `scrollIntoViewIfNeeded()` before measuring a position (smooth scrolling), or the touch lands in the wrong place.
- **Tests on `getComputedStyle` colours:** they can be `lab()`/`oklch()`; convert with `toRgb` in `e2e/color.ts` before comparing to an rgb literal.
- **`impeccable generate` on sibling sections:** the four homepage sections have no shared parent, so a temporary wrapper `div` was added in `app/page.tsx` for the preview and removed afterwards with `git checkout -- app/page.tsx`. The accepted preview was rebuilt test-first, not carbonized. `live-generate` piped through `head` shows no output until it exits: write it to a file instead. Never commit while the helper is live (`live-server stop` restores `app/layout.tsx`).
- **Staging part of a file** (no interactive `git add -p` here): hash the wanted version into a blob and `git update-index --cacheinfo 100644,<blob>,<path>`; that is how the `id="model-shots"` line went into the hero commit apart from the carousel rewrite.
- **Smooth scrolling hides a failed scroll test:** `html` uses `scroll-smooth`, so `scrollY` reads 0 right after a wheel event. Wait (about 600 ms) before asserting a scroll was blocked, and confirm the test goes red first.
- **Local e2e reuses a running dev server** when not run with `CI=1`; `npm run dev` may still be running from this session (started in the background, port 3000).
- Windows. Bash and PowerShell both work. Python writes CRLF unless you open files with `newline=""`.
- Agent worktrees under `.claude/worktrees/` get picked up by Vitest and ESLint: remove them when done. A fresh checkout or worktree needs `npm ci`.
- e2e: `CI=1 npx playwright test` (builds and serves; uses installed Chrome, D-15). Specs must import `test`/`expect` from `e2e/fixtures.ts` (ESLint enforces it): its auto fixture aborts the contact server action so no e2e test can email Mason. On 2026-11-06 the dev server was stopped before running it (a precaution; not tested whether that is needed).
- `.env.local` holds the **real** `RESEND_API_KEY`, and local e2e reuses a running `npm run dev`. Never submit a valid form outside the fixture or against the real action. Never print the key.
- Vitest aliases `server-only` to its no-op (`vitest.config.mts`); Next's build still enforces it.
- Git Bash rewrites `/c` to `C:/` in arguments (e.g. `cmd /c`); run those from PowerShell.
- Playwright MCP (`@playwright/mcp@0.0.83`, Chrome) blocks `file:` URLs and only saves files inside the repo in `.playwright-mcp/`, now **gitignored** (commit `9870d92` on `feat/redesign`). A first screenshot can predate Tailwind's rebuild on the dev server: wait, then reshoot.
- **Scroll reveal and screenshots:** the `.reveal` blocks sit hidden until scrolled into view, so a full-page screenshot without scrolling shows blank sections. Capture with `page.emulateMedia({ reducedMotion: "reduce" })` (that is how the "after" images were taken). Lazy images also stay unloaded in unscrolled captures.
